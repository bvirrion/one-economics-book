\begin{solution}{exo:b1:solow-model:inefficient}
At once, $c$ jumps up, since $s$ falls and $y$ is unchanged. Afterwards $k$ falls
monotonically from $k^*$ to $k_g$. Along the way $c = f(k) - \dot k - (n + \delta)k$ with $\dot k < 0$, so
$c > f(k) - (n + \delta)k$; and $f(k) - (n + \delta)k$ rises as $k$ falls towards $k_g$, since its slope
$f'(k) - (n + \delta)$ is negative above $k_g$. So $c$ exceeds the old $c^* = f(k^*) - (n + \delta)k^*$ at
every date.
\end{solution}

\end{solution}

\begin{solution}{exo:b1:solow-model:exact}
$\dot z = (1 - \alpha)k^{-\alpha}\dot k = (1 - \alpha)k^{-\alpha}[sk^{\alpha} - (n + \delta)k] = (1 - \alpha)[s - (n + \delta)z]$. This is
linear: $z(t) = z^* + (z(0) - z^*)e^{-(1 - \alpha)(n + \delta)t}$ with $z^* = s/(n + \delta)$. For any $z(0) > 0$,
$z(t) \to z^*$, so $k(t) \to k^*$: the \omterm{def:b1:solow-model:steady-state}{steady state} is globally stable.
\end{solution}

\begin{solution}{exo:b1:solow-model:linear}
With $x = \ln k$, $\dot x = sf(e^x)e^{-x} - (n + \delta)$. Its derivative at $x^*$ is
$s[f'(k^*)k^* - f(k^*)]/k^* = s f(k^*)/k^*\,(\alpha_k - 1) = -(1 - \alpha_k)(n + \delta)$, using $sf(k^*)/k^* = n + \delta$.
So $\lambda = (1 - \alpha_k)(n + \delta)$ for $\ln k$; since $d\ln y = \alpha_k\, d\ln k$ near $k^*$, the same rate holds
for $\ln y$.
\end{solution}

\begin{solution}{exo:b1:solow-model:refute}
For example: countries with similar saving, population growth and
schooling having persistently very different incomes and no tendency to
converge; or the implied capital share staying far from the measured share
of income however human capital is measured; or poor countries with high
saving not growing faster than rich ones with the same saving.
\end{solution}
