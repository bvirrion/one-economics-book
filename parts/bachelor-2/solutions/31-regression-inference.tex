\begin{solution}{exo:b2:regression-inference:9}
With $\rho = 0$ the factor is $\sqrt{1} = 1$. More generally the factor is $\sqrt{1 + (m - 1)\rho_x\rho}$, with $\rho_x$
the correlation of the regressor within groups; with $\rho_x = 0$ it is 1 again: correlated errors matter only when the
regressor is correlated within groups too.
\end{solution}

\begin{solution}{exo:b2:regression-inference:10}
$\hat\beta_1 = \sum_iw_iy_i$ with $w_i = (x_i - \bar x)/\sum_j(x_j - \bar x)^2$; $\sum_iw_i = 0$ and $\sum_iw_ix_i = 1$.
A linear estimator $\sum_ic_iy_i$ has expectation $\beta_0\sum c_i + \beta_1\sum c_ix_i$, so it is unbiased for every
$\beta$ if and only if $\sum c_i = 0$ and $\sum c_ix_i = 1$. Write $c_i = w_i + d_i$: then $\sum d_i = 0$ and $\sum
d_ix_i = 0$, so $\sum w_id_i = 0$ since $w_i$ is linear in $x_i$. The variance is $\sigma^2\sum c_i^2 = \sigma^2(\sum
w_i^2 + \sum d_i^2) \geq \sigma^2\sum w_i^2$, with equality only if every $d_i = 0$.
\end{solution}

\begin{solution}{exo:b2:regression-inference:11}
With $A = (X'X)^{-1}X'$, $\operatorname{Var}(\hat\beta \mid X) = A\operatorname{Var}(u \mid X)A'$. With independent
errors $\operatorname{Var}(u \mid X) = \operatorname{diag}(\sigma_i^2)$ and $X'\operatorname{diag}(\sigma_i^2)X =
\sum_i\sigma_i^2x_ix_i'$, which gives the sandwich. If $\sigma_i^2 = \sigma^2$, the middle is $\sigma^2X'X$ and the
product is $\sigma^2(X'X)^{-1}$.
\end{solution}

\begin{solution}{exo:b2:regression-inference:12}
With one regressor, $\hat\beta_1 - \beta_1 = \sum_i(x_i - \bar x)u_i/S$, $S = \sum_i(x_i - \bar x)^2$. Let $x_g$ be the
value in group $g$. Then $\sum_i(x_i - \bar x)u_i = \sum_g(x_g - \bar x)\sum_{i \in g}u_i$, and the group sums are
independent with variance $m\sigma^2 + m(m - 1)\rho\sigma^2$. So the variance is $\sum_g(x_g - \bar x)^2m\sigma^2(1 + (m -
1)\rho)/S^2$; since $S = m\sum_g(x_g - \bar x)^2$, this is $\sigma^2(1 + (m - 1)\rho)/S$.
\end{solution}
